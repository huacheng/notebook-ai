# Notebook-AI 桌面端 UI 交互流程

## 整体布局结构

```
┌─────────────────────────────────────────────────────────────────┐
│  Toolbar (54px)                                                 │
│  [Logo+Version] ─────────────────── [Model] [Plugins] [Lang] [WS Status] [Logout]
├──────────┬────────────────────────────────────┬─────────────────┤
│ Sidebar  │  Main Content Area                 │ (Right Panel)   │
│ (272px)  │                                    │ (扩展位)         │
│          │  NotebookTabs                      │                 │
│ ┌──────┐ │  ┌─────────────────────────────┐   │                 │
│ │ Top  │ │  │ notebook-area (互斥渲染)    │   │                 │
│ │ L1/L2│ │  │  - PluginManager            │   │                 │
│ │      │ │  │  - ModelManager             │   │                 │
│ ├──────┤ │  │  - GitHistoryPanel          │   │                 │
│ │ Div  │ │  │  - FileViewer (+SplitView)  │   │                 │
│ ├──────┤ │  │  - NotebookCreationPanel    │   │                 │
│ │Bottom│ │  │  - Notebook                 │   │                 │
│ │Library│ │  │  - WelcomeScreen           │   │                 │
│ └──────┘ │  └─────────────────────────────┘   │                 │
└──────────┴────────────────────────────────────┴─────────────────┘
```

**关键尺寸:**
- 顶栏高度: `--toolbar-height: 54px`
- 侧边栏宽度: `--sidebar-width: 272px` (可拖拽调整)
- 右侧面板: 300px (展开) / 24px (收起)
- 内容区左右内边距: `--space-xl: 24px`

## 1. 认证流程

```
App 启动
    │
    ├─ 检查认证状态 (checkAuthStatus)
    │      │
    │      ├─ authRequired=false → 直接进入 AuthenticatedApp
    │      │
    │      └─ authRequired=true
    │             │
    │             ├─ authMode='token' → TokenLoginPage (Token 登录)
    │             │
    │             └─ authMode='password'
    │                    ├─ LoginPage (邮箱密码)
    │                    └─ RegisterPage (注册)
    │
    └─ 认证成功 → AuthenticatedApp
```

**相关组件:** `LoginPage`, `TokenLoginPage`, `RegisterPage`

## 2. 侧边栏交互 (ProjectSidebar)

侧边栏分为**上下两部分**，中间有可拖拽分隔线。

### 2.1 L1 层级 - 项目列表 (ProjectList)

```
┌─────────────────────┐
│ PROJECTS            │
├─────────────────────┤
│ 项目A   [⋯]         │  ← 点击进入 L2, ⋯ 菜单: Rename/Export/Delete
│   2 notebooks       │
│ 项目B   [⋯]         │
│   5 notebooks       │
├─────────────────────┤
│ [New] [Import]      │  ← 新建/导入项目
└─────────────────────┘
```

**交互:**
| 操作 | 效果 |
|------|------|
| 点击项目行 | `setActiveProject(id, path)` → 进入 L2 |
| 点击 ⋯ 按钮 | 显示菜单: Rename / Export / Delete |
| 点击 New | 显示内联输入框，创建新项目 |
| 点击 Import | 选择 `.tar.gz` 文件导入项目 |

### 2.2 L2 层级 - 文件浏览 (FileBrowser)

```
┌─────────────────────┐
│ ← 项目名            │  ← 点击返回 L1
├─────────────────────┤
│ [Files][Git][Deliv] │  ← 三个子标签页
├─────────────────────┤
│ 面包屑: / > dir > ..│
│ [Upload][+File][+Dir][↓All][Refresh]
├─────────────────────┤
│ ↩ ..                │  ← 返回上级目录
│ 📁 .worktrees/      │  ← 普通目录: 点击进入
│ 📓 task-xxx/   [⋯]  │  ← Notebook 目录: 点击进入 + 更新 workspaceDir
│ 📄 file.txt   [↓][✕]│  ← 文件: 点击打开 FileViewer
├─────────────────────┤
│ [New] [Import]      │  ← 新建/导入 Notebook (仅在项目根目录显示)
└─────────────────────┘
```

**三个子标签页:**

| 标签 | 内容 | 说明 |
|------|------|------|
| Files | FileSection | 浏览项目文件，支持上传/创建/删除 |
| Git | GitHistoryPanel | Git 提交历史和 diff 查看 |
| Deliverables | FileSection | 交付物目录，路径根据 workspaceDir 动态变化 |

**Deliverables 路径逻辑:**
- 在 Notebook 目录内时 → 显示该 Notebook 的 `.deliverables/`
- 在项目根目录时 → 显示项目级 `.deliverables/`

### 2.3 Library 面板 (底部)

```
┌─────────────────────┐
│ LIBRARY             │
├─────────────────────┤
│ [Files] [Git]       │  ← 两个子标签页
├─────────────────────┤
│ 📄 reference.pdf    │  ← 全局共享资源库
│ 📄 template.docx    │  ← 文件可拖拽到 Notebook 输入框
│ 📁 .memory/         │  ← 只读系统目录
└─────────────────────┘
```

**特殊规则:**
- `.memory/` 目录只读 (readOnlyPath)
- 根级 `.` 开头文件和 `MEMORY.md` 不可删除 (noDeleteFilter)

## 3. 主内容区渲染优先级

主内容区 (`notebook-area`) 采用**互斥渲染**模式:

```javascript
// 渲染优先级 (高 → 低)
if (pluginPanelOpen)      → <PluginManager />
else if (modelPanelOpen)  → <ModelManager />
else if (gitTabOpen)      → <GitHistoryPanel /> (keep-alive 模式)
else if (hasActiveFile)   → <FileViewer /> (可能触发 SplitView)
else if (notebookLoading) → <NotebookLoadingScreen />
else if (creatingNotebook)→ <NotebookCreationPanel />
else if (hasNotebook)     → <Notebook />
else                      → <WelcomeScreen />
```

### Split View 触发条件

```javascript
const inSplitView = hasActiveFile && hasNotebook
  && !pluginPanelOpen && !modelPanelOpen && !fileViewerMaximized;
```

当同时打开文件和 Notebook 时，自动进入左右分栏模式:
- 左侧: FileViewer
- 右侧: Notebook
- 中间: 可拖拽分隔线 (splitRatio: 0.2 ~ 0.8)

## 4. 标签页系统 (NotebookTabs)

### 4.1 普通模式 - 单行标签

```
┌────────────────────────────────────────────┐
│ [NB-1 ×] [NB-2 ×] [file.ts ×] [data.json ×]│
└────────────────────────────────────────────┘
```

### 4.2 Split View 模式 - 双栏标签

```
┌─────────────────────┬──────────────────────┐
│ [file.ts ×]         │ [NB-1 ×] [NB-2 ×]    │
│ (文件标签)           │ (Notebook 标签)       │
└─────────────────────┴──────────────────────┘
```

**交互行为:**

| 操作 | 效果 |
|------|------|
| 点击 Notebook 标签 | `deactivateFileTab()` + `setActiveNotebookTab(id)` |
| 点击文件标签 | `setActiveFileTab(tabId)` |
| 点击 × 关闭 | `closeNotebookTab(id)` / `closeFileTab(tabId)` |
| 标签闪烁徽章 | 后台 Notebook 有更新 (`tabNotifications[id]`) |
| 加载中转圈 | 文件正在加载 (`file.loading`) |

**标签名截断:** 超过 20 字符显示 `...`

## 5. Notebook 创建流程

```
点击侧边栏 [New] 按钮
    │
    ├─ 显示内联输入框 (输入 Notebook 名称)
    │     └─ 标题验证: MAX_TITLE_LENGTH, 非法字符检查
    │
    └─ 按 Enter 或点击 Create 提交
          │
          ├─ CreateOverlay 显示进度
          │     phase: creating → done (✓) → idle
          │
          └─ 后端流程 (projects.ts):
                │
                ├─ 1. 创建 worktree 目录 (git worktree add)
                ├─ 2. 生成 .notebook.json 文件 (正确标题)
                ├─ 3. 创建 Session (sessionManager.createSession)
                ├─ 4. session.notebook = notebook (替换为正确对象)
                ├─ 5. 数据库插入 (db.createNotebook)
                └─ 6. Auto-send "/task-ai:auto load" (异步非阻塞)
```

**创建完成后:** 自动刷新文件列表，新 Notebook 出现在侧边栏。

## 6. 文件操作交互 (FileSection)

### 6.1 工具栏操作

| 按钮 | 功能 | 备注 |
|------|------|------|
| Upload (↑) | 选择文件上传 | 支持多选 |
| New File (+📄) | 创建空文件 | 内联输入文件名 |
| New Folder (+📁) | 创建目录 | 内联输入目录名 |
| Download All (↓) | 下载当前目录为 zip | 仅 showDownloadAll=true 时显示 |
| Refresh (⟳) | 刷新文件列表 | 清除缓存后重新获取 |

### 6.2 文件/目录操作

| 操作 | 触发方式 | 效果 |
|------|---------|------|
| 打开文件 | 点击文件行 | `onFileClick(subPath, filename)` |
| 进入目录 | 点击目录行 | `navigateInto(dirName)` |
| 返回上级 | 点击 `..` 行 | `navigateUp()` |
| 拖拽文件 | 拖动文件行 | 复制 `[file: relPath]` 到剪贴板 |
| 下载文件 | 点击 ↓ | 触发浏览器下载 |
| 删除 | 点击 ✕ → 确认 | 两次点击确认删除 |

### 6.3 拖拽上传

```
外部文件拖入 FileSection 区域
    │
    ├─ 显示 Drop Overlay ("Drop to upload")
    │
    └─ 松开鼠标
          │
          ├─ XHR 上传 + 进度条显示
          │
          └─ 完成 → 自动刷新文件列表
```

### 6.4 特殊过滤器

| 过滤器 | 用途 | 示例 |
|--------|------|------|
| `noDragFilter` | 禁止拖拽 | `.notebook.json` 文件 |
| `noDeleteFilter` | 禁止删除 | `.status.json`, `.working`, `.claude` |
| `readOnlyPath` | 只读目录 | `.memory/` 及其子目录 |

## 7. 连接状态与通知

### 7.1 WebSocket 连接状态

```
App 启动
    │
    └─ useWebSocket(sessionId)
          │
          ├─ connecting → connected (成功)
          │                   │
          │                   └─ 定期心跳 + 延迟测量
          │
          └─ 断开 → 自动重连 (指数退避)
                      │
                      └─ wsReconnectExhausted → 显示刷新 Banner
```

### 7.2 延迟指示器 (SignalBars)

| 延迟范围 | 信号格数 | 颜色 |
|----------|---------|------|
| < 50ms | 4 bars | 绿色 (#4ade80) |
| 50-150ms | 3 bars | 黄色 (#facc15) |
| 150-300ms | 2 bars | 橙色 (#fb923c) |
| >= 300ms | 1 bar | 红色 (#f87171) |
| 未连接 | 0 bars | 灰色 |

### 7.3 桌面通知 (useNotification)

**触发条件:** 浏览器标签页隐藏时 (`document.hidden`)

| 事件 | 通知标题 | 通知内容 |
|------|---------|---------|
| Cell 执行完成 | "Task Complete" | "Claude finished processing" |
| 需要用户输入 | "Input Required" | "Claude needs your input" |

**去抖:** 500ms 内不重复通知 (`NOTIFY_DEBOUNCE_MS`)

## 8. 滚动位置持久化 (useScrollRestoration)

```javascript
// 三种恢复场景
├─ 切换 Notebook 标签时 → 恢复该 Notebook 的滚动位置
├─ 用户滚动时 → 保存位置 (debounce 200ms)
└─ 浏览器标签可见性变化时 → 恢复滚动位置
```

**存储:** `localStorage` 键 `nb-scroll-${notebookId}`

## 11. 状态管理要点 (Zustand Store)

### 关键状态字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `sidebarLevel` | `'L1' \| 'L2'` | 侧边栏层级 |
| `activeProjectId` | `string \| null` | 当前项目 ID |
| `activeNotebookTabId` | `string \| null` | 当前 Notebook 标签 ID |
| `activeFileTabId` | `string \| null` | 当前文件标签 ID |
| `openNotebooks` | `Record<string, NotebookEntry>` | 已打开的 Notebooks |
| `openFiles` | `Record<string, FileEntry>` | 已打开的文件 |
| `workspaceDir` | `string \| null` | 当前工作目录 (影响 Deliverables 路径) |
| `wsStatus` | `'connecting' \| 'connected' \| 'disconnected'` | WebSocket 状态 |
| `sessionId` | `string \| null` | 当前会话 ID |

### 持久化恢复 (onMount)

```javascript
useEffect(() => {
  // 恢复 active project
  const saved = localStorage.getItem('nb-active-project');

  // 恢复 notebook tabs
  restoreOpenNotebookTabs();

  // 恢复 file tabs
  restoreOpenFileTabs();

  // 恢复 last notebook
  const lastId = cacheGet('nb-last-notebook');
  if (lastId) restoreNotebook(lastId);
}, []);
```
