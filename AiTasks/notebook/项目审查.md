## P0 — 高优先级（HIGH severity）

### P0-1: D2 DNS rebinding 绕过 SSRF 检查
- **文件**: `url-capture.ts:44-56, 80`
- **问题**: `dns.lookup()` 解析后检查私有 IP，但原始 URL 传给 `page.goto()`。Playwright 自行 DNS 解析，攻击者控制的 DNS 可先返回公网 IP（通过检查），再返回 `127.0.0.1`（到达内部服务）
- **修复**: 用 Playwright `page.route('**/*')` 拦截所有请求检查目标 IP，或解析 IP 后用 IP 直连 + Host header

### P0-2: D2 WebSocket maxPayload 无限制
- **文件**: `index.ts` (WebSocketServer 构造), `ws-handler.ts:173`
- **问题**: `ws` 库默认 `maxPayload` 为 100 MB，单个 WS 客户端可发送 100 MB JSON 载荷，耗尽服务器内存
- **修复**: `new WebSocketServer({ server, maxPayload: 25 * 1024 * 1024 })`

### P0-3: D2 HTML 内容直传 TipTap 未消毒
- **文件**: `FileViewerEditor.tsx:23`
- **问题**: `format === 'html'` 时 `content` 直接传给 TipTap，StarterKit 非安全消毒器，`onerror` 等事件属性可存活
- **修复**: `DOMPurify.sanitize(content)` 后再传给 TipTap
